# 📊 Sales Data Analysis - Mini Project

## 📁 Project Overview

This mini project analyzes and visualizes a fictional sales dataset using **Python**. It includes data cleaning, analysis of sales trends, identification of top-performing products, and generation of visualizations to support business insights. This project demonstrates fundamental skills in **data manipulation**, **data visualization**, and **basic data analytics** using popular Python libraries like `pandas`, `matplotlib`, and `numpy`.

---

## 🛠️ Technologies Used

- **Python 3**
- **pandas** – Data manipulation and cleaning
- **numpy** – Numerical operations
- **matplotlib** – Data visualization

---

## 📂 Project Structure

``` bash
sales-analysis-project/
│
├── sales_data.csv # Sample dataset containing sales records
├── sales_analysis.py # Main Python script for data processing and visualization
└── README.md # Project documentation (this file)

```
---

## 📈 Features

- Load and validate sales data from a CSV file
- Clean the data by handling missing values
- Convert date columns to proper datetime format
- Extract **Month** and **Year** from date for trend analysis
- Calculate **total sales per product**
- Analyze **monthly sales trends**
- Identify and display the **top-selling product**
- Visualize:
  - **Total Sales per Product** (bar chart)
  - **Monthly Sales Trend** (line chart)
